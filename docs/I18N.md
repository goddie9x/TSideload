# I18N conventions (shared: desktop GUI + iOS app)

Both tracks ship English + Vietnamese. One key namespace, two files per app.

## Files

- Desktop GUI: `apps/desktop/gui/src/i18n/en.json`, `apps/desktop/gui/src/i18n/vi.json`
- iOS app: its own `en.lproj` / `vi.lproj` (or equivalent), mirroring the same keys

## Key rules

1. Keys are `lower_snake` grouped by screen: `<screen>.<element>.<variant>`
   - `app.title`, `app.subtitle`
   - `devices.title`, `devices.refresh`, `devices.empty`, `devices.trust_hint`
   - `install.pick_ipa`, `install.start`, `install.success`, `install.error`
   - `auth.apple_id`, `auth.password`, `auth.twofa_prompt`, `auth.twofa_hint`
   - `certs.import_p12`, `certs.import_provision`, `certs.not_implemented`
   - `common.cancel`, `common.ok`, `common.retry`, `common.close`
2. **No string concatenation** — if a sentence needs a value, the key's string
   contains a `{name}` placeholder and the code substitutes it.
3. Vietnamese strings use full diacritics; keep the same tone as English
   (plain, no marketing fluff).
4. When adding a key, add it to **both** `en.json` and `vi.json` in the same
   commit. The iOS track mirrors new keys in its own localization files.
5. Do not rename keys — the on-device app may reference them for shared
   source-feed strings.

## Example

```json
{
  "app": { "title": "TSideload", "subtitle": "Free iOS sideloading" },
  "devices": {
    "title": "Devices",
    "refresh": "Refresh",
    "empty": "No device found. Connect your iPhone via USB and tap \"Trust\".",
    "count": "{n} device(s) connected"
  },
  "common": { "cancel": "Cancel", "ok": "OK", "retry": "Retry", "close": "Close" }
}
```
